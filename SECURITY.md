# Security Policy

Swarm is intended only for authorized CTF, lab, and security-research scopes.

Do not submit API keys, Feishu App Secrets, cookies, session files, private target data, or live exploit evidence in public issues. If you discover a credential exposure or a vulnerability in the framework itself, contact the repository owner privately through their GitHub profile before publishing details.

Before opening an issue, remove organization names, production hosts, user data, access tokens, challenge flags, and any artifact that is not safe to redistribute.
